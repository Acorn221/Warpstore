# Security

gpu-db is alpha software. Don't expose it to untrusted networks without a root password, TLS
(`--require-secure-transport`) and a firewall. By default it listens on 127.0.0.1 only.

To report a vulnerability, please open a private security advisory on the repository (GitHub:
Security > Report a vulnerability) rather than a public issue. Include the version / commit and
steps to reproduce.
